# Sports Performance Analytics – FIFA Player Dataset

## 📌 Project Title
**Sports Performance Analytics using FIFA Player Data**

## 📊 Dataset Description
This project uses FIFA player data to analyze important player attributes and overall performance. The dataset contains information about **499 football players** and **8 attributes**.

The dataset can be used for basic sports performance analysis, comparison of players, and understanding how different player attributes relate to overall and potential ratings.

## 📋 Columns
The dataset contains the following columns:

- ID
- Name
- Age
- Overall
- Potential
- Preferred Foot
- Position
- Finishing

### Important Attributes
- **Overall** – Overall rating of the player.
- **Potential** – Potential rating of the player.
- **Age** – Age of the player.
- **Preferred Foot** – Player's preferred foot.
- **Position** – Main playing position.
- **Finishing** – Finishing ability of the player.

## 🎯 Objective
The main objectives of this project are:

1. To study FIFA player performance data.
2. To compare players based on their ratings and attributes.
3. To identify important factors used in sports performance analysis.
4. To understand player strengths using statistical data.
5. To perform basic exploratory data analysis (EDA) on the dataset.

## 👀 How to View the Dataset
The dataset is available as a **CSV file**, so GitHub can display it directly in the browser.

1. Open `sports_data_base_dav_1_project.csv`.
2. Select the **Preview** tab.
3. The dataset will be displayed as a table.
4. You can also download the CSV and open it in Microsoft Excel.
